# Getting Support

> **Project status:** design phase. There is no software to run yet, so most
> "support" right now is really design discussion — which is welcome.

## Where to go

| You want to… | Go to |
|---|---|
| Ask a question about the design or direction | [GitHub Discussions][discussions] → **Q&A** |
| Share an idea or suggestion | [GitHub Discussions][discussions] → **Ideas** |
| Report a bug (once there's code) | **Issues** → Bug report template |
| Request a feature | **Issues** → Feature request template (or Discussions first if it's open-ended) |
| Propose an architecture change | [ADR process](docs/adr/0000-adr-process.md) |
| Report a security vulnerability | **Privately** — see [`SECURITY.md`](SECURITY.md). Never a public issue. |
| Report Code of Conduct concerns | See [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) |

**Please don't use the issue tracker for questions.** Issues are for actionable,
specific bugs and feature requests. Questions belong in Discussions, where
they're easier for others to find later.

## Before you ask

- Check the [documentation](docs/index.md), especially
  [`docs/architecture.md`](docs/architecture.md),
  [`docs/protocol.md`](docs/protocol.md), and the
  [glossary](docs/glossary.md).
- Search existing [Discussions][discussions] and
  [issues](https://github.com/OWNER/InterruptingCow/issues) — your question may
  already be answered.
- Once there's an operations guide, check
  [`docs/operations/runbook.md`](docs/operations/runbook.md) and
  [`docs/development/troubleshooting.md`](docs/development/troubleshooting.md).

## Response expectations

InterruptingCow is maintained by volunteers in their spare time. There is **no
SLA** for questions, issues, or feature requests. Security reports are the
exception — see [`SECURITY.md`](SECURITY.md) for those timelines.

A clear, reproducible report with the relevant context will always get a better
and faster response than a vague one.

## Commercial support

None is offered. The software is [AGPL-3.0-or-later](LICENSE); you are free to
run it yourself, modify it, and pay someone else to do so, subject to the
license.
